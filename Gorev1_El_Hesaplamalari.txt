Görev 1: Koordinat Dönüşümü (Window to Viewport) Hesaplamaları

Bu görevde, matematiksel (dünya) koordinat sistemimizdeki noktaları, bilgisayar ekranındaki piksellere dönüştürüyoruz.

Verilen Değerler:
- Dünya (Window) Sınırları: X ekseni [-150, 150], Y ekseni [-100, 100]
  - Window Genişliği (W_x) = 150 - (-150) = 300
  - Window Yüksekliği (W_y) = 100 - (-100) = 200

- Ekran (Viewport) Sınırları: Başlangıç (50, 30), Bitiş (430, 290)
  - Viewport Genişliği (V_x) = 430 - 50 = 380
  - Viewport Yüksekliği (V_y) = 290 - 30 = 260

Ölçekleme Çarpanları (Scale):
- S_x = V_x / W_x = 380 / 300 = 1.2666...
- S_y = V_y / W_y = 260 / 200 = 1.3

Formüller ve Y-Flip Mantığı:
Processing'de ekranın sol üst köşesi (0,0)'dır ve Y ekseni aşağı doğru büyür. Bizim matematiksel dünyamızda ise Y yukarı doğru büyür. Bu yüzden Y ekseninde (Y-Flip) dönüşüm yapmamız gerekir. Dünyanın en üst noktasını (Y=100), ekranın en üstüne (Y=30) sabitleyerek çözüyoruz.

- X_ekran = V_xmin + (X_dunya - W_xmin) * S_x
- X_ekran = 50 + (X_dunya + 150) * (380/300)

- Y_ekran = V_ymin + (W_ymax - Y_dunya) * S_y
- Y_ekran = 30 + (100 - Y_dunya) * 1.3

Test Edilen 5 Noktanın El Hesabı:

1) W(0, 0)
   X = 50 + (0 + 150) * 1.266 = 50 + 190 = 240
   Y = 30 + (100 - 0) * 1.3 = 30 + 130 = 160
   Sonuç: Ekranda (240, 160) pikselinde çıkar.

2) W(150, 100)
   X = 50 + (150 + 150) * 1.266 = 50 + 380 = 430
   Y = 30 + (100 - 100) * 1.3 = 30 + 0 = 30
   Sonuç: Ekranda (430, 30) pikselinde çıkar. (Tam sağ üst köşe)

3) W(-150, -100)
   X = 50 + (-150 + 150) * 1.266 = 50 + 0 = 50
   Y = 30 + (100 - (-100)) * 1.3 = 30 + 260 = 290
   Sonuç: Ekranda (50, 290) pikselinde çıkar. (Tam sol alt köşe)

4) W(75, -50)
   X = 50 + (75 + 150) * 1.266 = 50 + 285 = 335
   Y = 30 + (100 - (-50)) * 1.3 = 30 + 195 = 225
   Sonuç: Ekranda (335, 225) pikselinde çıkar.

5) W(-30, 80)
   X = 50 + (-30 + 150) * 1.266 = 50 + 152 = 202
   Y = 30 + (100 - 80) * 1.3 = 30 + 26 = 56
   Sonuç: Ekranda (202, 56) pikselinde çıkar.
